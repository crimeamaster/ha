# Wildberries Price Tracker Bot

Telegram бот для отслеживания цен товаров на Wildberries с автоматическими уведомлениями об изменениях.

## 🚀 Возможности

- 📦 Отслеживание цен товаров с Wildberries
- 🔔 Автоматические уведомления об изменении цен
- 🎯 Установка целевых цен
- 📊 История изменений цен
- 🔍 Поиск товаров по ссылкам
- 📱 Удобный интерфейс через Telegram

## 📋 Требования

- Python 3.8+
- Telegram Bot Token (получить у @BotFather)
- Доступ к интернету

## 🛠️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd wildberries-price-tracker
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте Telegram бота:**
   - Напишите @BotFather в Telegram
   - Создайте нового бота командой `/newbot`
   - Скопируйте полученный токен

4. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл и добавьте ваш BOT_TOKEN
```

5. **Запустите бота:**
```bash
# Простой запуск
python bot.py

# Или используйте скрипт запуска (рекомендуется)
python run.py
```

### Тестирование парсера:
```bash
python test_parser.py
```

## 📱 Использование

### Основные команды:

- `/start` - Начать работу с ботом
- `/add [ссылка]` - Добавить товар для отслеживания
- `/list` - Показать список отслеживаемых товаров
- `/remove [номер]` - Удалить товар из отслеживания
- `/help` - Показать справку

### Как добавить товар:

1. Найдите товар на Wildberries
2. Скопируйте ссылку на товар
3. Отправьте команду `/add` с ссылкой или просто отправьте ссылку

**Примеры:**
```
/add https://www.wildberries.ru/catalog/12345678/detail.aspx
https://www.wildberries.ru/catalog/87654321/detail.aspx
```

### Уведомления:

Бот отправляет уведомления в следующих случаях:
- Цена изменилась более чем на 5%
- Цена достигла установленной целевой цены

## 🗄️ База данных

Бот использует SQLite для хранения данных:
- **users** - информация о пользователях
- **tracked_products** - отслеживаемые товары
- **price_history** - история изменений цен
- **notifications** - отправленные уведомления

## ⚙️ Настройки

В файле `config.py` можно изменить:
- `POLLING_INTERVAL` - интервал проверки цен (в минутах)
- `PRICE_CHANGE_THRESHOLD` - порог изменения цены для уведомлений (в процентах)

## 🔧 Разработка

### Структура проекта:

- **bot.py** - Основная логика Telegram бота
- **wb_parser.py** - Парсинг данных с Wildberries API

- **price_monitor.py** - Фоновый мониторинг цен

1. Создайте новый обработчик в `bot.py`

3. Обновите документацию

## 🐛 Устранение неполадок

### Бот не отвечает:
- Проверьте правильность BOT_TOKEN
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок

### Не работает парсинг товаров:
- Wildberries может изменить API
- Проверьте доступность сайта
- Обновите User-Agent в `wb_parser.py`

### Проблемы с базой данных:
- Убедитесь в правах на запись в директорию
- Проверьте целостность файла базы данных
